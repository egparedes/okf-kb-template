# How-to guides

Each guide solves one task in a knowledge base generated from the template.
They assume you have done [Your first knowledge base](../tutorials/first-knowledge-base.md)
or know the basics.

**Set up**

- [Install the kb launcher](install-the-cli-launcher.md): one global `kb`
  command for every knowledge base.
- [Run several knowledge bases](multiple-knowledge-bases.md) on one machine.
- [Set up Obsidian](set-up-obsidian.md): plugins, settings, writing by hand,
  Web Clipper.
- [Enable search](enable-search.md) with qmd.
- [Use CI on GitHub](ci-and-github.md).

**Bring in material**

- [Connect Zotero](connect-zotero.md) for papers and books.
- [Connect KaraKeep](connect-karakeep.md) to archive web pages.
- [Link local files](link-local-files.md) such as slides in a synced folder.
- [Import a vault](import-a-vault.md) from Obsidian or Logseq.

**Keep it healthy**

- [Maintain the knowledge base](maintain-the-knowledge-base.md): the report,
  duplicates, unlinked mentions, the graph.
- [Update from the template](update-from-the-template.md).
