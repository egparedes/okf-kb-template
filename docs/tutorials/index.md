# Tutorials

The tutorials take you through the template by doing. Follow them in order,
on a machine where you can install tools.

1. [Your first knowledge base](first-knowledge-base.md): install the
   prerequisites, generate a knowledge base, open it in Obsidian, ingest a
   first source with an agent, ask a question, and commit. About 30
   minutes.
2. [Your first agent session](first-agent-session.md): work with the three
   skills (ingest, query, maintain), review what the agent wrote, and mark
   pages as reviewed.

When you know what you want to do, the [how-to guides](../how-to/index.md)
are shorter.
